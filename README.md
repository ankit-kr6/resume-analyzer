# Resume Analyzer + Skill Gap Detector

A Python-based tool that analyzes your resume against a target job role and identifies skill gaps with a match score.

## Features
- Upload PDF resume
- Select a target job role
- View matched skills and missing skills
- Get a match score with feedback

## Requirements
- Python 3.10+
- pip

## Setup Instructions

### 1. Clone the repository
git clone https://github.com/YOUR-USERNAME/resume-analyzer
cd resume-analyzer

### 2. Install dependencies
pip install -r requirements.txt

### 3. Run the application
streamlit run app.py

### 4. Use the app
- Browser opens automatically at http://localhost:8501
- Upload a PDF resume
- Select your target job role
- View your skill gap report
